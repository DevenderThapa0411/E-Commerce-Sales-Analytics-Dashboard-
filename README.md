# E-Commerce-Sales-Analytics-Dashboard-
 # 📊 Madhav E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview

This project is an interactive *Power BI dashboard* developed to analyze Madhav E-Commerce sales data. The dashboard provides insights into sales performance, profitability, customer behavior, payment methods, product categories, and regional sales trends to support data-driven business decisions.

---

## 🚀 Objectives

- Analyze overall sales and profit performance.
- Identify top-performing states and customers.
- Compare product category and sub-category performance.
- Monitor monthly profit trends.
- Analyze customer payment preferences.
- Create an interactive dashboard for business reporting.

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel (Data Source)

---

## 📈 Dashboard KPIs

- Total Sales Amount: *438K*
- Total Profit: *37K*
- Average Order Value: *121K*
- Total Quantity Sold: *6K*

---

## 📊 Dashboard Features

- KPI Cards
- Sales by State
- Sales by Customer
- Quantity by Category
- Quantity by Payment Mode
- Monthly Profit Trend
- Profit by Sub-Category
- Quarter-wise Slicer
- Interactive Filters

---

## 🔍 Key Insights

- Maharashtra generated the highest sales.
- Clothing was the highest-selling product category.
- Printers contributed the highest profit among all sub-categories.
- Most customers preferred Cash on Delivery (COD) as the payment method.
- Monthly profit showed noticeable fluctuations, with higher profits during October and November.
